# 新 environment 人工体验与验收

日期：2026-10-01。代码已接入，未启动 Godot；以下为预期行为，等待用户手动测试。

## 先看界面（隔离预览）

登录后结束当前通讯，在普通终端逐条输入。开机阶段可用 F12 跳过；需要时先输入 `debug 114514 skip_login`。

| 命令 | 内容 |
|---|---|
| `debug 114514 env normal` | 普通日，无待查项目 |
| `debug 114514 env device` | 设备疑点，复测后可校准 |
| `debug 114514 env mystery` | 未解变化，复测和标记关注 |
| `debug 114514 env sea` | 海域比例尺、浮标／声纳占位、船只／飞行器航迹及红色历史雷区示意 |
| `debug 114514 env clear` | 退出隔离预览，恢复正式玩家数据 |

预览中不会执行正式任务、保存快照、改变绩效或触发剧情；关闭界面不会自动退出预览。切换账号时会清除预览。地图正方形占位等待用户手绘，无无人机功能。

## 操作（2026-10-01 改为命令终端）

使用一般模式下原有的底部输入框输入命令，Enter 仅执行输入内容；S/R/F 不直接触发操作。Tab 切换近海／远海，上下键调出历史命令。左侧仅展示最新反馈，无标题、外框或滚动条；长反馈自动折行，超出可见范围的旧内容移出展示。命令可带 `env` 前缀，也可直接输入。

| 命令 | 操作 |
|---|---|
| `manual` / `help` / `guide` | 完整操作说明页面，包含指令、流程与图例 |
| `scan` / `collect` | 约 2.4 秒采集，不自动提交 |
| `status` / `issues` | 简报 / 带编号的疑点清单 |
| `select 1` / `select ocean` | 选择疑点或设施，地图用 `[ ]` 标记对应设施 |
| `retest` / `mark` / `calibrate` | 当前所选疑点复测 / 关注开关 / 校准 |
| `next` | 下一疑点并选择对应设施 |
| `report` | 提交日报；允许保留未确认疑点 |
| `map nearshore` / `map sea` | 两种地图 |
| `details` | 实时仪表总览 |
| `details atmosphere/ocean/geophysics/composition/events` | 对应分类详情；每次只输入一个分类 |
| `details evidence` | 全部采集快照、当前观测来源、疑点说明、复测与关注记录 |
| `history` / `history older` / `history newer` | 日报档案和翻页 |
| `clear` / `exit` | 清空反馈 / 返回桌面 |

地图、详情、说明与历史页均使用底部通用输入框。地图右侧只显示环境简报；当前选择只在地图以 `[ ]` 表示，本站与无目标不显示选择框。点击图标选择，点击圆盘空白处取消选择；切换地图不会清空正在输入的命令。`drone` 提示尚未接入，不进行飞行。

## 正式流程测试（建议用专门账号）

先执行 `debug 114514 env clear`，再输入 `exit` 返回终端。

1. 输入 `env`，检查 CRT 效果、字号、布局、命令输入与滚动反馈；调整窗口大小后输入区和地图仍对齐。
2. 没采集时输入 `report`，应提示先采集，不增加绩效。
3. 输入 `scan`，检查字符进度条；约 2.4 秒后只显示采集完成，日报仍未提交。
4. 用 `details evidence` 查看快照、`details` 查看实时读数。采集快照保持稳定；重新打开不重新采集。存在疑点时输入 `issues`、`select 1`、`retest`，复测提供当前读数或无数据说明。
5. 重复输入 `retest`，确认不重新随机抽取结果；输入 `mark` 标记、`next` 切换。未解变化不能以 `calibrate` 随意消除。
6. 提交日报，输入 `history` 检查的采集时间、快照、复测和关注记录；提交后不改写原记录。
7. 重复输入 `report`／`env report`，检查 `perf status` 或个人档案，无重复奖励。
8. Day0 不由 env 自动加分；Day1 起首次日报沿用单次 +1 日常分，不再逐项加分／追加全勤分。后续配额及奖励平衡可再调整。
9. 提交时观测台应仍可正常浏览；`exit` 退出后才显示完成回电。马上重开 env／mail 时，待发通讯继续等待，避免重叠。
10. `profile` 第二页应显示今日／配额、累计绩效、缺口、日报状态及最近 5 份环境得分来源。完整日报最多留 30 份。
11. 保存、退出并重进，检查历史保留。当前跨日机制沿用登录推进：已完成日报的次日登录会推进；Day0 仍有原教程推进规则。
12. 切换另一个账号，检查不会读到前一账号的日报。老存档日报会补成历史记录，不再次发奖。

## SVG 矢量地图接入

配置文件：`SCRT/data/env_observation.json`。`map_texture` 先为空，继续显示正方形占位。用户绘制冷战时期风格的 SVG 矢量地形；将 SVG 放入项目后填写对应路径，例如 `res://assets/maps/island.svg`（示例文件尚未创建），无需先转换成 PNG。

建议采用正方形 `viewBox`、透明背景，并将本站位置放在画布中心。底图绘制岛屿轮廓、等高线、道路及静态地物，使用清晰的线条和简化符号；网格、扫描线、设备状态、目标航迹与交互标记由程序叠加。绘制顺序为地形 → 网格与距离环 → 扫描线 → 标记，带背景的底图也不会遮住网格。近海底图目前显示在逻辑尺寸 410×410 的方形范围，定稿后再对齐地形和设施坐标。

SVG 是可编辑的矢量源文件；Godot 当前会将它导入成纹理显示，并非运行时无限缩放的矢量渲染。接入时按实际窗口尺寸与最大放大需求设置 SVG 导入分辨率，避免低分辨率导入后放大导致模糊。当前底图整体带浅绿色调制，特殊状态颜色优先使用程序标记。

`regions[].position` 是相对圆盘半径的二维坐标，中心为 `[0,0]`，右／下为正；已有设施位置仅示意。近海半径默认 600 m、网格 50 m；海域半径 30 NM、网格 5 NM。`contacts` 默认为空；正常游戏没有编造的远海实时航迹。

反馈时请标明：使用的命令／按键、所在游戏日、正常还是 debug 预览、截图、预期与实际。优先反馈布局、字大小、提示是否看得清、采集节奏和复测是否有用。

## 无人机扩展接口

EnvViewer 提供 `register_command_extension(command_name, handler)` 和 `unregister_command_extension(command_name)`。handler 接收 `Array[String]` 参数并返回反馈字符串；后续可注册 `drone` 根命令，在模块中处理 status、route、photo 等子命令。注册只接入命令，不自动实现飞行、存档或拍照。内置环境命令保留自身流程。

地图沿用 regions / contacts 独立数据层，未来无人机模块可提供位置和航迹；固定传感器快照与无人机照片须按来源区分。具体无人机实现仍留待后续阶段。

## 本轮界面调整重点验收

1. 进入 env 后底部输入框与桌面相同，输入命令不会落到桌面、产生重叠输出；exit 后恢复普通命令。
2. 左侧无“命令终端”标题、外框和滚动条，多次执行 status 后显示最新反馈；窗口缩放后反馈正确折行。
3. 点击设施或目标图标显示方括号；点击地图空白取消。本站与无目标不加框。输入 select / next 与点击选择一致。
4. 输入一半命令时按 Tab，地图切换但输入内容保留，字母不触发环境操作。
5. manual / help 打开操作说明与图例；map 返回地图。右侧不再显示当前选择和图例。
6. 详情和历史页底部输入仍可工作，提交防重复与全屏通讯队列行为继续按前述流程验证。
