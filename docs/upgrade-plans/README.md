**最新决定：demo 暂不加入无人机，先完善周围环境监视界面。** 2026-10-01 已启动开发；观测台、正方形地图占位、短采集、复测／关注、日报历史和个人档案绩效概览已接入，等待用户体验。未运行 Godot。

[ENV、地图、空中无人机与 camera 联动方案](env-observation-improvement-plan.md)

已确定方向：短时值班、可选发现、用户手绘地图、指令控制空中无人机、低面数 3D 场景按需拍照、旧式图传处理、最低离地高度、限高限距、半球形通信范围与禁飞区。目前无水下无人机。日报与个人档案绩效整合也包含在正文中，数值待确认。

demo 顺序：观测台与日报 → 固定观测来源的地图监视 → 疑点复测与历史记录 → 按需联动 camera/radio、绩效和正式内容。

后续无人机方案保留：单机单任务、航点航线、三档高度、有限拍摄角度、悬停拍照、固定起降、分层制作场景；3D、指令飞行和拍照均不纳入 demo 本轮开发。
