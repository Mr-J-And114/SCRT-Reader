针对你的超宽全景图（3904x1088，宽高比 3.6:1）进行了优化。

  已修复的问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 问题 1：视口太小，画面放大过度
**原因：** viewport_size: [0.3, 0.3] 只显示 30% 的区域
**修复：** viewport_size: [0.9, 0.7] 显示 90% 宽度，70% 高度

### 问题 2：转动不流畅
**原因：**
- rotation_radius: 0.15 太小，转动范围受限
- rotation_angle_range: 45° 对于宽屏来说太小
- pan_speed: 0.008 太慢

**修复：**
- rotation_radius: 0.25（增大转动半径）
- rotation_angle_range: 60°（增大角度范围）
- pan_speed: 0.02（加快转动速度）

### 问题 3：视差效果太强
**原因：** parallax_scale: 0.05 对于宽屏来说偏移太大
**修复：** parallax_scale: 0.03（降低视差强度）

  参数调整指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### viewport_size（视口大小）
- **太小**：画面放大过度，看不到全景
- **太大**：画面太小，细节不清晰
- **推荐**：宽度 = 图片宽高比 / 5
  - 16:9 (1.78) → 0.6
  - 21:9 (2.33) → 0.75
  - 3.6:1 (3.6) → 0.9

### rotation_radius（旋转半径）
- **太小**：转动范围受限，卡顿
- **太大**：转动过度，失去中心
- **推荐**：0.1 - 0.3
  - 标准图：0.15
  - 宽屏：0.2-0.25
  - 超宽屏：0.25-0.3

### rotation_angle_range（角度范围）
- **太小**：左右转动不够
- **太大**：转到边缘看不到内容
- **推荐**：30° - 70°
  - 标准图：45°
  - 宽屏：50-60°
  - 超宽屏：60-70°

### pan_speed（转动速度）
- **太慢**：转动卡顿，不流畅
- **太快**：难以精确控制
- **推荐**：0.01 - 0.03
  - 标准图：0.012
  - 宽屏：0.015-0.02
  - 超宽屏：0.02-0.025

### parallax_scale（视差强度）
- **太小**：没有 3D 感
- **太大**：画面扭曲，晕眩
- **推荐**：0.02 - 0.08
  - 标准图：0.05
  - 宽屏：0.03-0.04
  - 超宽屏：0.02-0.03

  测试建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. **启动游戏并打开摄像头**
   ```
   camera view 1
   ```

2. **测试转动**
   - 按 ←→ 键左右转动
   - 应该流畅，能看到大部分画面

3. **测试视差**
   - 转动时观察前景和背景的移动速度
   - 应该有轻微的深度感，但不扭曲

4. **调整参数**
   - 如果还是太放大：增大 viewport_size
   - 如果转动不够流畅：增大 pan_speed
   - 如果转动范围不够：增大 rotation_radius 和 rotation_angle_range
   - 如果视差太强：降低 parallax_scale

  快速计算公式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

已知图片尺寸，快速计算推荐参数：

1. **计算宽高比**
   宽高比 = 图片宽度 / 图片高度
   你的图：3904 / 1088 = 3.59

2. **viewport_size 宽度**
   宽度 = min(0.95, 宽高比 / 4)
   你的图：3.59 / 4 = 0.90

3. **viewport_size 高度**
   高度 = 宽度 * 0.75
   你的图：0.90 * 0.75 = 0.68 ≈ 0.7

4. **rotation_radius**
   半径 = 0.1 + (宽高比 - 1.5) * 0.08
   你的图：0.1 + (3.59 - 1.5) * 0.08 = 0.27 ≈ 0.25

5. **rotation_angle_range**
   角度 = 40 + (宽高比 - 1.5) * 10
   你的图：40 + (3.59 - 1.5) * 10 = 60.9 ≈ 60
