  预渲染图片功能使用指南
════════════════════════════════════════════════════════════════

本功能允许你使用预先制作好的图片，而不是依赖 shader 后处理。
适合不熟悉图像处理的作者，或需要精确控制视觉效果的场景。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  功能说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. **Shader 后处理模式（默认）**
   - use_prerendered: false
   - 使用 shader 实时计算照明效果
   - 需要深度图
   - 效果动态，但需要技术知识

2. **预渲染图片模式（推荐新手）**
   - use_prerendered: true
   - 使用预先制作的图片
   - 不需要深度图（但有深度图效果更好）
   - 效果固定，但易于制作

  配置示例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

{
  "cameras": {
	"cam_example": {
	  "name": "示例摄像头",
	  "unlocked": true,

	  // 基础图片
	  "base_image": "camera_main.jpg",
	  "depth_map": "camera_depth.jpg",  // 可选，但推荐

	  // ★ 启用预渲染模式
	  "use_prerendered": true,

	  // ★ 预渲染图片
	  "nightvision_image": "camera_nvg.jpg",    // 夜视图
	  "infrared_image": "camera_heat.jpg",      // 红外图

	  // 照明模式（初始模式）
	  "light_mode": "none"
	}
  }
}

  图片制作指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 1. 基础图（base_image）
   - 正常的摄像头画面
   - 建议分辨率：1920x1080 或更高
   - 格式：JPG 或 PNG

### 2. 深度图（depth_map）[可选但推荐]
   - 黑白图，白色=近景，黑色=远景
   - 用于 Spotlight 模式的深度感
   - 即使使用预渲染，深度图也能增强效果

### 3. 夜视图（nightvision_image）
   - 绿色调的夜视效果
   - 可以用 Photoshop/GIMP 制作：
	 1. 复制基础图
	 2. 去色（转黑白）
	 3. 调整亮度/对比度
	 4. 添加绿色色调（色相/饱和度）
	 5. 添加噪点（滤镜 > 噪点）

### 4. 红外图（infrared_image）
   - 热力图效果（蓝→紫→红→橙→黄）
   - 可以用 Photoshop/GIMP 制作：
	 1. 复制基础图
	 2. 去色（转黑白）
	 3. 应用渐变映射（蓝→红→黄）
	 4. 调整对比度

  照明模式说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### None（无照明）
- 画面变暗
- 不需要额外资源

### Spotlight（聚光灯）
- 局部照亮效果
- 需要：深度图
- 使用 shader 后处理（不支持预渲染）

### Nightvision（夜视）
- 绿色夜视效果
- 预渲染模式：使用 nightvision_image
- Shader 模式：需要深度图，实时计算

### Infrared（红外）
- 热力图效果
- 预渲染模式：使用 infrared_image
- Shader 模式：需要深度图，实时计算

  常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 可以混用两种模式吗？
A: 可以！同一个摄像头可以：
   - Spotlight 用 shader（需要深度图）
   - Nightvision/Infrared 用预渲染图

Q: 预渲染图片的分辨率要求？
A: 建议与基础图相同，至少 1920x1080

Q: 如果没有提供预渲染图会怎样？
A: 系统会自动回退到 shader 模式（需要深度图）
   如果深度图也没有，会提示"缺少资源"

Q: 可以只提供部分预渲染图吗？
A: 可以！例如只提供 nightvision_image
   那么 Infrared 模式会使用 shader 或提示缺少资源

  推荐工作流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 新手作者（推荐预渲染）
1. 准备基础图
2. 用 PS/GIMP 制作夜视图和红外图
3. 设置 use_prerendered: true
4. 测试效果

### 进阶作者（推荐 Shader）
1. 准备基础图
2. 制作深度图（黑白图）
3. 设置 use_prerendered: false
4. 调整 shader 参数（light_radius, light_falloff）

### 混合模式（最佳效果）
1. 准备基础图 + 深度图
2. 制作预渲染图（夜视、红外）
3. 设置 use_prerendered: true
4. Spotlight 自动使用 shader + 深度图
5. Nightvision/Infrared 使用预渲染图
