# SCRT-Reader Core

基于 Godot 4.7.1 的 CRT 终端模拟器与可扩展阅读框架。当前 main 文件树提供软件框架源码，不包含正式游戏的剧情、人物、立绘、语音或故事盘。旧版提交历史按作者决定保留，历史中仍可能访问旧内容；本次无剧情保证仅适用于替换后的文件树，详见发布说明。

使用 Godot 4.7.1 编辑器导入 `SCRT/project.godot`，运行主场景。首次使用按终端提示注册合成账号或自己的本地账号；没有预置管理员密码。账号和运行设置位于工程旁的 saves 目录，应保持私有。不要将运行后生成的数据加入版本库。

将有权使用的 ZIP 格式 `.scp` 内容包放入 `SCRT/vdisc/`（自行创建），输入 `scan`，根据 `load` 帮助加载。空目录是正常状态。输入 `help` 查看命令；`camera`、通讯、邮件和任务由内容包提供数据。

支持 CRTML、通用文档模板、图片、音频、OGV 视频、拨号和 DTMF、RADIO、环境观测及 Mod API。FFmpeg 扩展和录制语音库未随仓库分发；自行安装有合法授权、兼容本机 Godot 的依赖后才能使用相关格式。Mod 脚本具有宿主权限，只加载可信内容。

ZIP 文件名建议 UTF-8。未分发来源未核实的完整 GBK 表；内置回退只覆盖标点、全角字母和数字。旧 GBK 汉字文件名不能保证正确读取，请先用合法工具转为 UTF-8 ZIP。
