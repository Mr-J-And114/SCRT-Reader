## 软件简介

**SCRT-Reader**（SCP CRT Reader）是一款基于 Godot 4.6 引擎开发的沉浸式终端风格文字阅读器。它模拟了一台上世纪 80-90 年代风格的 CRT 显示终端，通过命令行交互方式让用户阅读和探索故事内容。

软件围绕 **SCP 基金会**的世界观设计，但其故事包系统完全开放——任何人都可以制作自己的故事包，创造独特的交互式阅读体验。

### 核心特性

- **CRT 终端模拟**：逼真的扫描线、色差、荧光闪烁、噪点等 CRT 显示效果
- **打字机文字效果**：文字逐字显示，支持自定义速度和停顿控制
- **命令行交互**：通过输入命令浏览虚拟文件系统、阅读文件
- **权限解锁系统**：多级安全等级与密码认证机制，实现渐进式叙事
- **故事包系统**：故事内容以 `.scp` 文件形式加载，完全数据驱动
- **多主题支持**：内置磷光绿、琥珀色、冷蓝、纯白四种配色主题
- **多用户系统**：支持多个用户账户，每个用户拥有独立的存档和个人档案
- **多媒体支持**：内置图片查看器和音频示波器播放器，故事包可包含图片与音频
- **环境音系统**：故事包可为不同目录配置背景环境音，增强沉浸感
- **全屏文档查看器**：长文档支持双栏分页阅读模式
- **自动存档**：进度按用户、按故事分别保存，下次加载自动恢复

### V0.3.x 版本新增

相比 V0.2.x，V0.3.x 版本增加了以下主要功能：

- 完整的多用户账户系统（注册、登录、修改密码、删除账户）
- 用户个人档案页面（含操作统计、系统评语等）
- 图片查看器（支持 PNG、JPG、JPEG、BMP、WebP、TGA）
- 音频播放器与示波器可视化（支持 OGG、WAV、MP3）
- 故事包环境音配置（可按目录设置背景音乐）
- 隐藏目录功能（故事包可隐藏特定目录不被 `ls` 显示）
- 全屏双栏文档查看器（支持 `---PAGE---` 分页标记）
- 音量控制命令（主音量、环境音、音效、媒体分通道调节）
- CRT-ML 新增标记：多媒体内联标记、涂黑遮蔽、原始文本块、更多文字效果
- 存档系统按用户隔离，每个用户拥有独立的游戏进度

## 安装与启动

### 导出版本（推荐）

1. 将 SCRT-Reader 可执行文件放在任意目录
2. 确保同一目录下存在 `vdisc/` 文件夹（首次运行会自动创建）
3. 将故事包文件（`.scp`）放入 `vdisc/` 文件夹
4. 双击可执行文件启动

目录结构示例：

```
SCRT-Reader/
├── SCRT-Reader.exe        (可执行文件)
├── vdisc/                 (故事包目录，自动创建)
│   ├── my_story.scp
│   └── another_story.scp
└── saves/                 (存档目录，自动创建)
    ├── _global.json       (全局配置)
    ├── Admin/             (管理员存档)
    │   ├── profile.json
    │   └── save_xxxx.json
    └── <用户名>/
        └── ...
```

### 在 Godot 编辑器中运行

1. 使用 Godot 4.6 打开 `SCRT/` 目录下的项目
2. 直接按 F5 运行
3. 故事包放在项目根目录的 `vdisc/` 文件夹内

## 用户系统

V0.3.x 版本引入了完整的多用户账户系统。每个用户拥有独立的存档数据和个人偏好设置。

### 登录

启动程序后首先进入身份验证界面。屏幕会显示已注册的操作员列表：

```
╔════════════════════════════════════╗
║  SCP FOUNDATION SECURE TERMINAL    ║
║     SECURE · CONTAIN · PROTECT     ║
╚════════════════════════════════════╝

身份验证系统 v2.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

已注册操作员:
  Admin (上次登录)

输入用户名登录，或输入 register 注册新账户。

操作员代号 [Admin]:
```

- 输入用户名后按 Enter，系统会要求输入密码（密码输入时显示为 `*` 号）
- 如果上次有登录记录，直接按 Enter 可以使用上次的用户名
- 首次运行时，系统内置一个管理员账户 `Admin`（默认密码 `admin`）
- 在登录界面输入 `exit` 或 `quit` 可退出程序

### 注册新账户

在登录界面输入 `register` 即可进入注册流程：

1. 输入用户名（2-20 个字符，不含特殊字符和空格）
2. 设置密码（至少 4 位）
3. 确认密码

注册成功后会自动登录并进入桌面模式。在注册过程中任何步骤输入 `cancel` 可取消。

### 用户管理

登录后可以使用以下用户相关命令：

| 命令 | 说明 |
|------|------|
| `whoami` | 显示当前登录的用户名和角色 |
| `profile` 或 `profile 1` | 查看个人档案第 1 页（基本信息） |
| `profile 2` | 查看个人档案第 2 页（统计数据、系统评语） |
| `users` | 列出所有已注册的用户 |
| `passwd` | 修改当前账户密码 |
| `birthday YYYY-MM-DD` | 设置出生日期 |
| `logout` | 注销当前账户，返回登录界面 |
| `deluser <用户名>` | 删除指定用户及其所有存档（需管理员权限或删除自身） |

**用户角色：**

- `admin`（管理员）：可以删除其他用户的账户
- `user`（普通用户）：只能删除自己的账户

**个人档案中记录的信息：**

- 用户名、角色、头衔、徽章
- 注册时间、最近登录时间、登录次数
- 命令执行次数、磁盘加载次数、文件阅读量、在线时长
- 主题偏好
- 系统评语（故事包可通过配置注入自定义评语）

```
╠══════════════════════════════════════════════════════════╣
```

## 操作说明

### 两种模式

SCRT-Reader 有两种工作模式：

| 模式 | 说明 |
|------|------|
| **桌面模式** | 登录后的默认模式。可以浏览、扫描和加载故事包，管理用户账户 |
| **磁盘模式** | 加载故事包后进入。可以浏览虚拟文件系统、阅读文件、解锁权限 |

### 桌面模式

登录后自动进入桌面模式。屏幕会显示欢迎界面：

```
╔══════════════════════════════╗
║       SCP FOUNDATION         ║
║   SECURE TERMINAL SYSTEM     ║
║      操作员: Admin           ║
╚══════════════════════════════╝

检测到 2 个虚拟磁盘。输入 scan 查看列表。
输入 help 查看可用命令。
```

**桌面模式常用操作：**

- 输入 `scan` 扫描并查看可用故事包列表（带进度条动画）
- 输入 `load 1` 加载第 1 个故事包
- 输入 `vdisc` 查看磁盘目录路径和数量
- 输入 `profile` 查看个人档案
- 输入 `help` 查看完整命令列表

扫描完成后会显示每个故事包的标题、作者、ID 和文件名，已有存档的故事会标注 `[存档]`。

### 磁盘模式

加载故事包后进入磁盘模式。此时你面对的是一个虚拟文件系统，通过命令浏览和阅读文件。

**基本工作流程：**

1. **`ls`** — 查看当前目录下有哪些文件和文件夹
2. **`cd <目录名>`** — 进入某个文件夹
3. **`open <文件名>`** — 打开并阅读某个文件
4. **`back`** — 返回上一级目录

**文件列表中的标记含义：**

| 标记 | 颜色 | 含义 |
|------|------|------|
| `[DIR]` | 蓝色 | 可进入的目录 |
| `[FILE]` | 绿色 | 可直接打开的文件 |
| `[DIR] 【LOCKED LV.N】` | 红色 | 需要等级 N 权限才能进入的目录 |
| `[FILE] 【LOCKED LV.N】` | 红色 | 需要等级 N 权限才能打开的文件 |
| `[FILE] [PASSWORD]` | 黄色 | 需要输入文件专属密码才能打开 |

**解锁权限：**

当你遇到权限不足的文件或目录时，需要通过 `unlock` 命令输入密码来提升权限等级：

1. 输入 `unlock` 进入密码输入模式（密码输入时显示为 `*` 号）
2. 或直接输入 `unlock <密码>` 验证密码
3. 密码正确后权限等级会提升，之前锁定的内容会解锁
4. 在密码输入模式中输入 `cancel` 可取消

故事中的文件内容通常包含线索，引导你找到下一个密码。仔细阅读每个文件！

**文件密码：**

部分文件除了需要权限等级外，还设有独立的文件密码。打开这类文件时系统会提示输入密码。文件密码与权限等级系统互相独立——即使你有足够的权限等级，仍需额外输入文件密码才能查看内容。

**查看状态：**

输入 `status` 可查看当前权限等级、已读文件数、已获取密码数等信息。

**卸载磁盘：**

输入 `eject` 卸载当前故事包并返回桌面模式（进度会自动保存）。

### 键盘与鼠标操作

| 操作 | 说明 |
|------|------|
| `Enter` | 提交命令 |
| `↑` / `↓` | 浏览历史命令（最多保存 50 条） |
| `Tab` | 自动补全命令和文件名（多选项时显示可选列表） |
| `Space` / `Esc` | 跳过打字机动画，立即显示全部文字 |
| `PageUp` / `PageDown` | 上下滚动输出内容 |
| 鼠标滚轮 | 上下滚动输出内容 |
| 鼠标左键选中 + 右键 | 复制选中文字到剪贴板 |
| 鼠标左键点击链接 | 部分文本（如多媒体标记）支持点击交互 |

### 多媒体功能

V0.3.x 版本支持在故事包中嵌入图片和音频文件。

**图片查看器：**

当你 `open` 一个图片文件（PNG、JPG、JPEG、BMP、WebP、TGA）时，会自动打开全屏图片查看器。按 `Esc` 或 `Q` 关闭查看器返回终端。

**音频播放器（示波器）：**

当你 `open` 一个音频文件（OGG、WAV、MP3）时，会自动打开全屏音频播放器，显示实时波形可视化。按 `Esc` 或 `Q` 关闭返回终端。

**环境音：**

故事包可以为不同的目录配置背景环境音。当你通过 `cd` 命令进入配置了环境音的目录时，音乐会自动开始播放；进入子目录时环境音会持续播放；离开该目录范围后环境音会自动停止。

### 文档查看器

当使用 `profile` 命令查看个人档案时，系统会启动全屏文档查看器。文档查看器以双栏分页布局显示内容：

- 按 `←` / `→` 或 `A` / `D` 翻页
- 按 `Esc` 或 `Q` 关闭查看器返回终端

故事创作者可以在文本中使用 `---PAGE---` 标记来手动控制分页位置。

### 主题切换

输入 `theme` 命令可查看可用主题并切换。内置四种主题：

| 主题名 | 说明 |
|--------|------|
| `phosphor_green` | 经典磷光绿，默认主题，还原老式 CRT 终端 |
| `amber` | 复古琥珀色，模拟琥珀色单色显示器 |
| `cool_blue` | 冷蓝色调，现代终端风格 |
| `white` | 纯白高对比度 |

使用方法：`theme <主题名>`，例如 `theme amber`。切换主题时需输入 `Y` 确认，确认后终端会重新初始化以应用新主题。

### 音量控制

使用 `volume`（简写 `vol`）命令查看和调节音量：

- `volume` — 查看所有通道的当前音量
- `volume <通道> <数值>` — 设置指定通道的音量（0-100）

可用通道：

| 通道名 | 别名 | 说明 |
|--------|------|------|
| `master` | `main`、`all` | 主音量 |
| `ambient` | `amb`、`bg` | 环境音 |
| `sfx` | `sound`、`fx` | 音效（系统提示音） |
| `media` | `music` | 媒体播放音量 |

示例：`volume ambient 50` 将环境音音量设为 50%。

### 存档系统

- **自动保存**：每次解锁密码、阅读文件、卸载磁盘时自动保存
- **手动保存**：在磁盘模式下输入 `save`
- **清除存档**：
  - `clearsave` — 清除当前故事的存档
  - `clearsave all` — 清除全部存档

存档按用户隔离，保存在 `saves/<用户名>/` 目录下。每个用户对每个故事有独立的存档，互不干扰。再次加载同一故事时会自动恢复进度。

## 制作自己的故事包

### 概述

SCRT-Reader 的故事包是一个标准的 **ZIP 压缩文件**，扩展名改为 `.scp`。故事包中包含一个配置文件 `manifest.json` 和若干内容文件（文本、图片、音频等），按文件夹组织成虚拟文件系统。

**制作故事包不需要任何编程知识**——你只需要：

1. 用文本编辑器编写故事内容（`.txt` 文件）
2. 准备多媒体素材（可选）
3. 编写一个 `manifest.json` 配置文件
4. 将所有文件打包为 ZIP 并重命名为 `.scp`
5. 将文件放入 `vdisc/` 目录

### 故事包文件结构

一个功能完整的故事包内部结构如下：

```
my_story/                      (顶层文件夹，名称随意)
├── manifest.json              (必须) 故事配置文件
├── welcome.txt                故事入口/欢迎文件
├── notice.txt                 公告或提示
├── reports/                   报告类文件
│   ├── report_001.txt
│   └── report_002.txt
├── personnel/                 人员档案
│   ├── researcher_a.txt
│   └── agent_b.txt
├── classified/                高密级文件
│   └── secret_doc.txt
├── media/                     多媒体文件
│   ├── photo.jpg              图片文件
│   ├── photo.txt              图片描述文件（可选，自动隐藏）
│   ├── recording.ogg          音频文件
│   └── recording.txt          音频描述文件（可选，自动隐藏）
└── audio/                     环境音文件（建议通过 hidden_dirs 隐藏）
    └── background.ogg
```

**注意事项：**

- 所有文本文件必须使用 **UTF-8 编码**（也支持 GBK 编码自动识别）
- 文件夹结构可以自由设计，没有固定要求
- `manifest.json` 必须存在，否则故事包无法被识别
- 如果 ZIP 内所有文件都在同一个顶层文件夹下，程序会自动去除该前缀
- 支持的图片格式：PNG、JPG、JPEG、BMP、WebP、TGA
- 支持的音频格式：OGG、WAV、MP3
- **媒体描述文件**：如果某个 `.txt` 文件与同目录下一个媒体文件同名（仅扩展名不同，如 `photo.txt` 对应 `photo.jpg`），该 `.txt` 文件会自动从 `ls` 列表中隐藏

### manifest.json 详解

`manifest.json` 是故事包的核心配置文件。以下是包含所有可用字段的完整示例：

```json
{
  "story": {
    "id": "my_story_id",
    "title": "故事标题",
    "author": "作者名",
    "version": "1.0",
    "description": "故事简介（可选）"
  },

  "settings": {
    "start_path": "/",
    "start_clearance": 0
  },

  "hidden_dirs": ["audio"],

  "permissions": {
    "/personnel/": 1,
    "/classified/": 4,
    "/classified/secret_doc.txt": 5
  },

  "passwords": {
    "1": "password_for_level_1",
    "3": "password_for_level_3",
    "5": "final_password"
  },

  "file_passwords": {
    "/classified/secret_doc.txt": {
      "password": "opensesame",
      "hint": "密码提示文字"
    }
  },

  "ambient": {
    "/": {
      "file": "audio/background.ogg",
      "volume": 0.3
    }
  }
}
```

以下逐一说明各配置段：

#### story（故事元数据）

| 字段 | 必须 | 说明 |
|------|------|------|
| `id` | 是 | 故事唯一标识符，用于存档关联。建议使用英文、数字和下划线 |
| `title` | 是 | 故事标题，显示在磁盘列表中 |
| `author` | 是 | 作者名 |
| `version` | 否 | 版本号 |
| `description` | 否 | 故事简介 |

> **重要**：`id` 是存档系统识别故事的唯一依据。修改 `id` 会导致用户之前的存档无法关联。

#### settings（运行设置）

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `start_path` | `/` | 加载故事后的初始目录 |
| `start_clearance` | `0` | 玩家的初始权限等级 |

#### hidden_dirs（隐藏目录）

字符串数组，列出需要对用户隐藏的目录名。这些目录不会在 `ls` 中显示，用户也无法通过 `cd` 进入。

```json
"hidden_dirs": ["audio", "assets"]
```

典型用途：隐藏存放环境音素材的目录。

#### permissions（权限表）

定义哪些路径需要什么等级的权限才能访问。键为路径字符串，值为所需权限等级（整数）。

```json
"permissions": {
  "/reports/secret.txt": 1,
  "/personnel/": 2,
  "/classified/": 4
}
```

规则：

- 路径以 `/` 开头
- 对目录设置权限会自动保护该目录及其下所有内容
- 对单个文件设置权限只保护该文件
- 同一路径被多个规则覆盖时取最高等级
- 权限等级从 0 开始，数字越大越机密，没有上限
- 未出现在权限表中的路径默认不需要权限（等级 0）

#### passwords（密码表）

定义可用的密码及其对应权限等级。键为权限等级（字符串形式的数字），值为密码字符串。

```json
"passwords": {
  "1": "alpha",
  "3": "hard2kill",
  "5": "wearethelight"
}
```

- 键是该密码对应的权限等级
- 值是密码字符串（区分大小写）
- 只有当密码等级高于当前等级时才生效

设计建议：

- 在低权限文件中放置线索，引导玩家猜出下一个密码
- 密码按等级递增设计，形成渐进式解锁体验

#### file_passwords（文件密码表）

为特定文件设置独立密码。与权限系统独立——即使有足够权限，仍需输入文件密码。

```json
"file_passwords": {
  "/classified/secret_doc.txt": {
    "password": "opensesame",
    "hint": "传说中开启宝藏的咒语"
  }
}
```

| 字段 | 说明 |
|------|------|
| 键 | 需要密码保护的文件路径（以 `/` 开头） |
| `password` | 正确的密码 |
| `hint` | 打开文件时显示的提示（可选） |

文件密码一旦解锁会保存在存档中。

#### ambient（环境音配置）

为特定目录配置背景环境音。

```json
"ambient": {
  "/": {
    "file": "audio/background.ogg",
    "volume": 0.3
  },
  "/classified/": {
    "file": "audio/tension.ogg",
    "volume": 0.5
  }
}
```

| 字段 | 说明 |
|------|------|
| 键 | 环境音生效的目录路径 |
| `file` | 音频文件在故事包内的路径 |
| `volume` | 音量，0.0 到 1.0，默认 1.0 |

也支持简写格式：`"/": "audio/background.ogg"`

规则：

- 环境音从当前目录向上查找，使用最近匹配的配置
- 子目录间切换时如果配置相同则持续播放
- 离开覆盖范围后自动停止
- 建议将音频文件放在单独目录并通过 `hidden_dirs` 隐藏

### CRT-ML 标记语言

故事文件（`.txt`）中可以使用 **CRT-ML** 标记语言来增强视觉效果。CRT-ML 兼容部分 Markdown 语法，显示时自动转换为富文本。

#### 标题

```
# 一级标题          主题色加粗，上下双线边框
## 二级标题         主题色加粗，下方单线
### 三级标题        主题色加粗
```

#### 分割线

以下写法均可（至少 3 个字符）：

```
---
===
───
━━━
```

#### 引用块

```
> 这是引用文字，以灰色缩进显示
```

#### 文字格式

| 标记 | 效果 | 说明 |
|------|------|------|
| `**文字**` 或 `{b}文字{/b}` | **粗体** | |
| `*文字*` 或 `{i}文字{/i}` | *斜体* | |
| `~~文字~~` 或 `{s}文字{/s}` | ~~删除线~~ | |
| `{u}文字{/u}` | 下划线 | |
| `` `代码` `` | `代码` | 等宽灰色 |

#### SCP 专用标记

| 标记 | 说明 |
|------|------|
| `[REDACTED]` | 红色加粗遮挡标记 |
| `[DATA EXPUNGED]` | 红色加粗数据删除标记 |
| `[CLASSIFIED]` | 黄色加粗机密标记 |
| `[ACCESS DENIED]` | 红色拒绝访问标记 |
| `[LEVEL N CLEARANCE REQUIRED]` | 黄色权限需求提示（N 为 0-5） |

以上标记不区分大小写。

#### 黑幕遮蔽

```
████████████                       CRT 荧光色的遮蔽方块
{blackout}████████{/blackout}      纯黑不发光的遮蔽方块
||被隐藏的文字||                    点击可揭示的遮蔽文字
```

#### 颜色标记

```
{color:颜色名}文字内容{/color}
```

主题语义色：

| 颜色名 | 别名 | 说明 |
|--------|------|------|
| `primary` | — | 主题主色调 |
| `secondary` | — | 主题辅色调 |
| `error` | `red` | 红色 |
| `warning` | `yellow` | 黄色 |
| `success` | `green` | 绿色 |
| `info` | `blue` | 蓝色 |
| `muted` | `gray`、`grey` | 灰色 |
| `dim` | — | 暗色 |

具名颜色：`orange`、`cyan`、`pink`、`gold`、`purple`、`silver`、`white`、`black`

自定义颜色：`{color:#FF5533}文字{/color}`

#### 机密标记框

```

{/classified}
```

等级 1-3 黄色边框，等级 4+ 红色边框。

#### 文字动画效果

| 标记 | 效果 |

| `{wave}文字{/wave}` | 波浪动画 |

#### 对齐

```

```

#### 表格


### 打字机控制标签

在文本中嵌入特殊标签控制打字机的输出节奏。支持花括号 `{}` 和方括号 `[]` 两种格式：

| 标签 | 说明 | 示例 |
|------|------|------|
| `{speed=数值}` | 设置打字速度（秒/字符） | `{speed=0.05}慢速文字{/speed}` |
| `{/speed}` | 恢复默认速度 | |
| `{pause=秒数}` | 暂停指定秒数 | `等一下……{pause=2}好了。` |
| `{delay=秒数}` | 同 `{pause}` | |
| `{clear}` | 清空屏幕 | |
| `{noskip}...{/noskip}` | 不可跳过的区段 | |

方括号兼容格式：`[speed=0.05]`、`[/speed]`、`[pause=2]`

使用技巧：

- 数值越大速度越慢，默认约 `0.008`
- 悬念处使用 `{pause=1}` 增强节奏感
- 重要内容使用 `{speed=0.03}` 吸引注意力

#### 变量替换

```
欢迎回来，{username} 操作员。
```

`{username}` 会被替换为当前登录的用户名。

### 打包与测试

#### 打包步骤

1. **准备文件**：确保所有 `.txt` 文件使用 UTF-8 编码保存

2. **创建 ZIP 文件**：
   - **Windows**：选中故事文件夹，右键 → 发送到 → 压缩(zipped)文件夹
   - **macOS**：选中故事文件夹，右键 → 压缩
   - **Linux**：`zip -r my_story.scp my_first_story/`

3. **修改扩展名**：将 `.zip` 改为 `.scp`

4. **放入 vdisc 目录**：复制到 SCRT-Reader 同级目录的 `vdisc/` 文件夹中

> **注意**：仅支持 ZIP 格式。RAR、7z 等需先转为 ZIP。若使用 7-Zip 打包且含中文文件名，建议启用 UTF-8 选项（`cu=on`）。

#### 测试

1. 启动 SCRT-Reader 并登录
2. 输入 `scan` 扫描磁盘
3. 使用 `load <编号>` 加载故事
4. 逐一检查：
   - 文件是否正常打开和显示
   - CRT-ML 标记是否正确渲染
   - 权限和密码系统是否按预期工作
   - 多媒体文件是否能正常打开
   - 环境音是否在正确目录播放
   - 存档和读档是否正常

### 常见问题排查

| 问题 | 可能原因 |
|------|----------|
| 故事包不出现在列表中 | 文件不在 `vdisc/` 目录中，或扩展名不是 `.scp` |
| 显示"无法识别的文件格式" | 不是 ZIP 格式，RAR/7z 需转换 |
| 加载后没有文件 | `manifest.json` 格式错误或不存在，检查 JSON 语法 |
| 中文显示乱码 | 文本文件未使用 UTF-8 编码 |
| 中文文件名异常 | 打包时未使用 UTF-8，用 7-Zip 加 `cu=on` |
| 权限设置不生效 | 检查路径是否以 `/` 开头 |
| CRT-ML 显示原始文本 | 效果标记用 `{}`，SCP 标记用 `[]` |
| 环境音不播放 | 检查 `ambient` 中的文件路径和文件是否存在 |
| 图片/音频无法打开 | 确认格式受支持，检查扩展名 |
| 存档无法恢复 | `story.id` 是否与之前一致 |
