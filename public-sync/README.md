# 公开工程维护

使用 Python 3.11+ 标准库和 Godot 4.7.1。源仓库通过参数传入，工具不保存本机私有绝对路径。公开工程运行本身不依赖源仓库。

在公开仓库目录依次执行，将占位参数换成本机路径：

```powershell
python public-sync/sync_public.py --dry-run --source "<私有仓库根目录>"
python public-sync/sync_public.py --sync --source "<私有仓库根目录>" --godot "<Godot-4.7.1可执行文件>"
python public-sync/sync_public.py --verify
git diff
git status --short
```

也可用 `SCRT_PUBLIC_GODOT` 环境变量指定引擎，或用 `--target` 指定独立目标。工具不执行 Git 提交、远端连接或推送。

`allowlist.toml` 逐文件定义生产代码；未登记的新源文件不读取、不复制。新增模块先审核内容、引用和版权，再登记精确路径。通用代码按 SHA-256 增量复制。`overrides/` 保存公开中立适配；每个生产适配固定来源 SHA 和行号范围。来源有变化只报告该文件的预期 SHA、实际 SHA 与适配行号，停止同步；审核其局部差异后再更新覆盖和 SHA，不需要重新分析整个工程。

同步工具、文档、测试与规则属于 maintained 文件，不由同步流程生成覆盖。目标中出现未知文件、生成文件被人工修改、源或配置在本轮改变，均停止；不要通过删除未知内容或直接更新状态绕过检查。

先 dry-run 冻结计划，再 sync。sync 在同卷候选目录检查白名单、文本/二进制许可哈希、内容泄露、资源契约和引用；有变化时还会自动在独立临时副本中导入 Godot、执行合成账号与内容包测试，并用第二个进程验证重载。通过后才替换登记生成文件。无变化的 sync 不重写任何文件，也不重复运行引擎。

`.sync-local/` 保存本地计划、逐文件来源/输出哈希、验证摘要和回滚备份；不进入 Git。摘要自身也接受敏感内容检查。多文件应用使用事务日志和逐文件原子替换，异常时恢复旧内容；不能声称跨文件的文件系统原子提交。进程被强制中断时会保留日志并阻止后续同步。确认没有其他同步进程、审阅日志后执行 `--recover`，再重新 dry-run。残留 apply.lock 也需要在确认原进程已退出后由维护者处理，工具不会擅自清除未知锁。

持锁后会再次核对来源、配置、目标状态和未知文件，防止验证期间的并发变化。所有本地状态路径也拒绝链接和 junction；原子替换失败时只清理由本次调用创建的临时文件。

规则的哈希词表用于拦截受限词，不保存原文。新增规则应同时覆盖源代码注释、JSON、场景、覆盖源、文档、夹具和报告。字体仅接受已核验的二进制 SHA；其他未经审核的二进制默认阻止。Git 工作树与完整索引严格检查；固定 Legacy 基线及祖先仅保留历史，基线后的每个可达提交均扫描完整文件树，重用旧 blob 也不能豁免。例外绑定唯一基线与 origin，无关闭未来扫描的开关。.git 从不作为源文件复制。历史范围及 Desktop 提交流程见 [发布说明](../docs/PUBLISHING.md)。

正式日常目标为连接 origin 的 `SCRT-Reader-remote`，原 Core 仅作恢复点。一次性 `--adopt-verified-core` 从逐项验真的原 Core 重建所有权，不自动认领同名文件、不复制旧状态。

同步故障测试为 `python -B public-sync/checks/test_sync.py`，Git 历史边界测试为 `python -B public-sync/checks/test_git.py`。夹具只用合成代码与临时 Git 仓库，不联网、不读取生产工程。大部分故障夹具模拟引擎；设置 SCRT_PUBLIC_GODOT 后另有一个合成小工程执行真实 Godot 门禁，未提供时会明确跳过。不要将夹具测试通过当作实际界面或作者试玩验收。

发布前仍应人工审阅 Git diff、资源授权和界面。普通代码更新无需 AI；只有新增模块、适配 SHA 冲突、版权不明确或检查失败时需要进一步审阅。

Git 属性关闭文本换行归一化，保留同步输出的准确字节和 SHA；不影响普通文本差异显示。不要启用会静默改写内容的 clean/smudge 过滤器，工作树与索引各自严格扫描，允许同步后的安全未暂存变化；提交前须核对全部 Changes，最终待提交树必须完整。
